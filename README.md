# 130心跳 · 川流百卅

四川大学130周年校园文创展示与场景化选购网页。

[在线体验](https://chuanliu-130-yuan.springpeace32.chatgpt.site/?v=1.3)

## 功能

三校区文化展示、24个商品款式、四问选品、解释型推荐、商品搜索筛选、六类礼盒、自由搭配与购物车。

## 使用

直接打开 index.html，无需安装依赖。assets、CSS与JavaScript文件须保持当前相对路径。

## 用户反馈迭代

三轮测试分别为10人、5人、3人，记录见 docs。未核实参与者跨轮是否重复，不将其表述为18名独立参与者，不声称未经测量的转化率或满意度提升。

## GitHub上传与Pages发布

将此文件夹内的全部内容上传到GitHub仓库根目录（index.html应直接出现在仓库首页文件列表中）。
若希望使用GitHub Pages，在仓库Settings → Pages中选择Deploy from a branch，再选择main分支、/(root)并保存。以GitHub返回的实际网站地址为准。
